# MCP server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve a stateless MCP server at `/mcp` whose tools are the `/api/v1` operations, dispatched in process through the same gin engine and visible by token scope.

**Architecture:** New package `internal/mcpserver`. At start it builds one tool per catalog operation (minus an exclusion list) from the generated OpenAPI document, plus a `wait` tool. Each `/mcp` request passes a bearer-only guard, gets a fresh `mcp.Server` holding the tools the token sees, and every tool call becomes an in-memory `/api/v1` request served by the engine with the caller's `Authorization`.

**Tech Stack:** Go 1.26, gin, Uber fx, `github.com/modelcontextprotocol/go-sdk` v1.6.1 (`mcp`), `github.com/google/jsonschema-go` (test only, comes with the SDK), swaggest openapi-go (existing).

**Spec:** `docs/superpowers/specs/2026-10-14-mcp-design.md`

## Global Constraints

- No comments in any file (user's global rule; hooks refuse them).
- Function bodies ≤ 20 lines, at most 2 levels of control-flow nesting.
- Tool name = `operationId`; `wait` tool `seconds` 1–120, default 120; `wait: true` → `?wait=120s`.
- Stateless Streamable HTTP with JSON responses (`StreamableHTTPOptions{Stateless: true, JSONResponse: true}`).
- Bearer only on `/mcp`; no bearer → `401` + `WWW-Authenticate: Bearer`.
- Excluded operations: `getOpenAPI`, `getMe`, `listTokens`, `createToken`, `revokeToken`, `createTeam`, `deleteTeam`, `putMember`, `removeMember`, `listUsers`, `getUser`, `setAdmin`, `deleteService`, `transferService`, `deleteQueue`, `unsetSecret`.
- Commits authored as the user, no `Co-Authored-By`; final history one commit per layer.

## Review Focus

- A tool argument that is not a parameter or body field (agent typo) → error result naming it, not silently dropped. Test in Task 4.
- A path argument containing `/` or spaces → escaped, never a different route. Test in Task 4.
- A numeric query argument (`limit: 20`) → `limit=20`, not `20.0` or `2e+01`. Test in Task 4 (arguments decoded with `UseNumber`).
- An empty bearer (`Authorization: Bearer `) on `/mcp` → `401`, never a cookie fallback. Test in Task 5.
- A waited call that ends before the final state → result carries the "Not final yet" note. Test in Task 4.

```go
func moveBodyTypes(spec *openapi31.Spec, ops []Operation) error {
	for _, op := range ops {
		if op.BodyType == "" {
			continue
		}
		if err := spec.SetupOperation(op.Method, DocPath(op.Path), moveBodyType(op.BodyType)); err != nil {
			return err
		}
	}
	return nil
}

func moveBodyType(bodyType string) func(*openapi31.Operation) error {
	return func(o *openapi31.Operation) error {
		content := o.RequestBody.RequestBody.Content
		content[bodyType] = content[jsonType]
		delete(content, jsonType)
		return nil
	}
}
```
