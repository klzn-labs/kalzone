# Agent-grade API (3b: capabilities) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An agent waits for a build, deployment or change request with one `?wait=` call, names releases as `latest`, `r42`, `sha:<prefix>` or a tag, deploys or promotes up to ten targets all or nothing in one request, changes config with a JSON merge patch, and finds where a variable is set with `GET /api/v1/config/search`.

**Architecture:** Everything is additive on top of 3a. The release domain resolves references (`ReleasesUsecase.Resolve`), and deploy reaches it through its `ReleaseLookup` adapter. Deploy plans every target exactly like a single call, refuses the batch on any failure, then writes all deployments with one repository call in one transaction (`ScheduleAll`). Envconfig turns a merge patch into the existing `ChangeSet` and runs it through the same `change` path as a revision; search is its own usecase over a `JSON_CONTAINS_PATH` query, filtered by `actor.Sees` through a catalog adapter. A new `internal/httpserver/wait` package polls the same usecase reads once a second until a final status, the deadline, the client leaving, or the server draining; operations opt in with `apispec.Operation.Waits`, which also documents the second status and the `wait` parameter.

**Tech Stack:** Go 1.26, Gin, Uber fx, GORM on MySQL 8, testify, swaggest/openapi-go (document), kin-openapi (response validation in the integration suite). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-12-agent-api-design.md`, sections 12–16 (3b), with sections 2, 4, 5, 17, 18 and 20 for the contract it extends. 3a (`docs/superpowers/plans/2026-10-12-agent-api.md`) is live on `main` at `75cf823`; the operation registry, parity test and response validation it built check every route this plan adds.

**How the code was checked:** every code block below was applied to a scratch worktree of `75cf823`, one commit per task in this order. ## Decisions

The spec leaves these points open; each is decided with the simplest correct design. The spec itself is not changed: none of them contradicts it.

| # | Point | Decision | Cost if wrong |
|---|---|---|---|
| 1 | Which calls take `?wait` | Exactly the spec's table: `getRelease`, `requestRelease`, `getDeployment`, `createDeployment`, `promoteDeployment`, `applyConfig`, `rollbackDeployment`, `getRequest`. "Any gated call that answered with a change request" is read as: any of those that became a change request. Config revisions, patches, secrets and queue changes answer at once. | An agent calls `GET /requests/:id?wait=` itself after a gated config change: one more call. Opting another operation in is `Waits: true` plus `wait.Started` in its handler. |
| 2 | What a waited gated call returns | The change-request body with its current `status`: `200` once it is `executed`, `failed`, `rejected`, `cancelled` or `expired`, else `202` + `Retry-After`. It does not return the deployment the request produced. | The agent reads `result` with `GET` on `poll`. Returning the deployment needs the request to record the deployment id. |
| 3 | `GET /releases/:ref?service=&wait=` | The reference is resolved once; the wait then follows that release id, so `latest` cannot move under a waiting caller. | None found. |
| 4 | Reference precedence | UUID, then `latest`, then `r<1-999999999>`, then `sha:`, then a tag (a valid image tag); anything else is `400`. A tag spelled `latest` or `r42` can only be named by id. Builds here tag `r1-0123456`, which stays a tag. | An image tagged `r42` must be deployed by id; changing the order is one `switch`. |
| 5 | A UUID of another service's release | Resolved per service, so it is `404` with the list hint (it was `400 that release belongs to another service`). Deploy keeps its old check as a guard on the adapter. | An agent that relied on the 400 message sees 404; nothing in the suite or docs did. |
| 6 | Which error leads a refused batch | The first gated target's `403 err_approval_required` when there is one (the spec's rule for gated targets), otherwise the first failure; `details.targets` lists every failing target `{index, code, message}`. | A caller fixing the first listed failure might see a different lead next time; all failures are always listed. |
| 7 | Where batch input is checked | The handler picks the form (`targets` with `service`/`environment`/`to` is `400 field targets`; neither is `400` naming the missing field). The usecase checks 1–10 targets, each complete, none repeated (`field: targets` or `targets[i]`). `service`, `environment` and `to` become optional in the schema. | None found; the 3a strict-body test now lists `targets` among the accepted fields. |
| 8 | Race between validation and the batch insert | `ScheduleAll` re-checks `in_progress` inside the transaction and answers `409` "nothing was deployed"; a duplicate deployment number retries the whole transaction up to 3 times. | Rare 409s under heavy concurrent deploys to the same targets; the caller retries. |
| 9 | Merge patch edge cases | `"env": null` is a `400` like `"spec": null` (it would wipe every variable); a non-string env value is `400 field env`; an unknown spec field is `400` naming the field with the spec's fields in the hint; `message` must be a string; any other top-level key, `secrets` included, is an unknown field. Unchanged values are dropped, so a patch that changes nothing is the existing `400 nothing changed`. | None found. |
| 10 | `415` | A new code `err_unsupported_media_type` mapped to `415`; `Operation.BodyType` documents `application/merge-patch+json` as the request content type. | None found. |
| 11 | Config search details | `key` must match the variable-name pattern (`UPPER_SNAKE_CASE`, platform-reserved names allowed); an unknown `env` is `404`; `team` is resolved through the teams usecase and a team the token is not granted is `403 err_team_not_granted` naming the slug. Sessions see every team, as everywhere else. Results are ordered by service slug, then environment; `value` is present for env matches (also when empty) and absent for secrets. Search is its own usecase (`app/envconfig/usecases/search`) and handler package, fed by a new `catalog.Directory` adapter, so `ConfigUsecase` and its fakes stay untouched. | A team with many services makes the in-memory filter scan all services once per call; fine for hundreds. |
| 12 | Drain and polling | `wait.NewDrain` is provided by fx and closed from `server.RegisterOnShutdown`; the integration suite exposes it as `Suite.Drain`. The poll interval is 1 s and `Retry-After` is always `5`. | None found. |

## Global Constraints

- Function bodies ≤ 20 lines, at most 2 levels of nesting, **no comments** in any file: Go, SQL, Markdown code samples, tests (user rule; a hook enforces it). `ALLOW_COMMENTS` is never used.
- One commit per layer, bottom-up: storage (Task 1), rules (Tasks 2–4), handlers + wiring + integration tests (Tasks 5–7), docs (Task 8). No fix/wip commits, no `Co-Authored-By`, do not push. Commit messages follow the repo style (an imperative sentence, no prefix).
- Tests run with `-p 1`: the MySQL-backed packages share one test database (`make test`).
- Everything is additive: no existing request or response shape changes. `/api/v1` stays in place; the build callbacks, `/agent/v1`, `/queued/v1`, the webhook and the web UI are untouched.
- Every new route is declared through `httpserver.API.Handle` with an `apispec.Operation`; the parity test and the response validation of the integration client must stay green.
- `?wait=<Go duration>`: above 0, at most 120 s, otherwise `400 field wait`, checked before anything is written. Final: release `built`/`failed`; deployment `succeeded`/`failed`/`cancelled`; request `executed`/`failed`/`rejected`/`cancelled`/`expired`. `200` when final, else `202` with the current object and `Retry-After: 5`. Polls the usecase about once a second; never uses the event bus.
- Release references: UUID, `latest` (built, highest number), `r42` (any status), `sha:<7–40 hex>` (newest built whose commit starts with it; two different commits is `400`), otherwise a tag (newest built with it); no match is `404` with hint `list releases with GET /api/v1/releases?service=<slug>`.
- Batch: `targets` 1–10, no repeats; every target validated like a single call first; any failure writes nothing and answers the leading error with `field: targets[i]` and `details.targets`; any target needing approval refuses the batch with `403 err_approval_required`; the answer is `202 {"items": [...]}` in target order.
- Config patch: `PATCH /api/v1/config/:service/:env`, `Content-Type: application/merge-patch+json` (else `415`), RFC 7396 over `{spec, env}` plus `message`, through the same validation, no-op check and approval gate as a revision (`201` or `202`).
- Config search: `GET /api/v1/config/search?key=` (+ `env`, `team`), scope `read`, current revisions only, secret names only, services the caller sees only, paged in memory.

## Review Focus

1. A waiting request ties up a handler for up to two minutes: when the caller hangs up or the control plane shuts down mid-wait, the handler must return at once rather than run out the clock. Task 5 `Test_Until_StopsWhenTheCallerGoesAway`, `Test_Read_ReturnsAtOnceWhenTheServerDrains`, and the integration test `Test_AWaitReturnsAtOnceWhenTheServerDrains`.
2. A deployment starts on one target between the batch's validation and its insert: nothing of the batch may be written. Task 1 `Test_ScheduleAll_WritesNothingWhenOneTargetIsRunning`; Task 3 `Test_DeployAll_WritesNothingWhenOneTargetFails`; Task 6 `Test_ABatchIsAllOrNothing`.
3. A token limited to one team searches for a key that other teams also set: it must see only its own services, and no secret value may appear anywhere. Task 1 `Test_Search_FindsCurrentEnvValuesAndSecretNamesOnly`; Task 4 `Test_Find_OrdersMatchesByServiceAndHidesOtherTeams`; Task 7 `Test_ConfigSearchFindsValuesAndSecretNamesInTheCallersTeams` (asserts the body lacks the secret).
4. A short `sha:` prefix that matches two different commits must not deploy whichever is newer; the same commit built twice must resolve to the newest build. Task 2 `Test_Resolve_RefusesAmbiguousAndForeignReferences`, `Test_Resolve_NamesReleasesTheWayPeopleDo`.
5. A merge patch that names keys without changing them, or nulls a key that is not set, must not write an empty revision or a misleading change request. Task 4 `Test_PatchChangeSet_KeepsWhatThePatchDoesNotName` (unchanged `KEEP` is not in `set_env`) and `Test_Patch_GoesThroughTheSameChecksAsARevision` (`nothing changed`).

Three additive repository capabilities. Releases gain single-row lookups that return `(release, found, error)` so the usecase can word the not-found error with the service's slug. Deployments gain `ScheduleAll`, which does for many targets in one transaction what the usecase's `clearWay` + `Create` do for one; `nextNumber` is split so the transaction can number rows. Config revisions gain `Search`: the JSON path is a bound parameter, the value is read from `env` only, so a secret's value cannot be selected.

```go
package mysql

import (
	"context"

	"github.com/adrianozp/platform/app/deploy/entities"
	"github.com/adrianozp/platform/pkg/apperror"
	"gorm.io/gorm"
)

const supersededMessage = "CONCAT('superseded before deployment #', number, ' started')"

var errStartedMeanwhile = apperror.Conflict("a deployment started meanwhile on one of the targets, nothing was deployed").
	WithHint("follow the running deployments with GET /api/v1/deployments?service=<slug>&env=<env>, then send the batch again")

func (r DeploymentRepository) ScheduleAll(ctx context.Context, ds []entities.Deployment) ([]entities.Deployment, error) {
	var err error
	for attempt := 0; attempt < numberAttempts; attempt++ {
		var created []entities.Deployment
		created, err = r.scheduleOnce(ctx, ds)
		if !isDuplicate(err) {
			return created, err
		}
	}
	return nil, err
}

func (r DeploymentRepository) scheduleOnce(ctx context.Context, ds []entities.Deployment) ([]entities.Deployment, error) {
	var created []entities.Deployment
	err := r.db.WithContext(ctx).Transaction(func(tx *gorm.DB) error {
		var err error
		created, err = scheduleEach(tx, ds)
		return err
	})
	return created, err
}

func scheduleEach(tx *gorm.DB, ds []entities.Deployment) ([]entities.Deployment, error) {
	created := make([]entities.Deployment, 0, len(ds))
	for _, d := range ds {
		next, err := scheduleIn(tx, d)
		if err != nil {
			return nil, err
		}
		created = append(created, next)
	}
	return created, nil
}

func scheduleIn(tx *gorm.DB, d entities.Deployment) (entities.Deployment, error) {
	if err := supersedePending(tx, d); err != nil {
		return entities.Deployment{}, err
	}
	if err := nothingInProgress(tx, d); err != nil {
		return entities.Deployment{}, err
	}
	number, err := nextNumberIn(tx, d.ServiceID, d.Environment)
	if err != nil {
		return entities.Deployment{}, err
	}
	d.Number = number
	model := fromDeployment(d)
	return d, tx.Create(&model).Error
}

func supersedePending(tx *gorm.DB, d entities.Deployment) error {
	return tx.Model(&deployment{}).
		Where("service_id = ? AND environment = ? AND status = ?", d.ServiceID, d.Environment, entities.StatusPending).
		Updates(map[string]any{"status": entities.StatusCancelled, "message": gorm.Expr(supersededMessage), "finished_at": d.CreatedAt}).Error
}

func nothingInProgress(tx *gorm.DB, d entities.Deployment) error {
	var running int64
	err := tx.Model(&deployment{}).
		Where("service_id = ? AND environment = ? AND status = ?", d.ServiceID, d.Environment, entities.StatusInProgress).
		Count(&running).Error
	if err == nil && running > 0 {
		return errStartedMeanwhile
	}
	return err
}
```

```go
package entities

import (
	"regexp"
	"strconv"
	"strings"

	"github.com/adrianozp/platform/pkg/apperror"
)

type ReferenceKind string

const (
	ByID     ReferenceKind = "id"
	ByLatest ReferenceKind = "latest"
	ByNumber ReferenceKind = "number"
	ByCommit ReferenceKind = "commit"
	ByTag    ReferenceKind = "tag"
)

const ReferenceForms = "a release id, latest, r<number>, sha:<7 to 40 hex characters> or a tag"

var (
	idPattern     = regexp.MustCompile(`^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$`)
	numberPattern = regexp.MustCompile(`^r[1-9][0-9]{0,8}$`)
	prefixPattern = regexp.MustCompile(`^[0-9a-f]{7,40}$`)
	errReference  = apperror.Invalid("a release is named by " + ReferenceForms).WithHint("send latest, r42, sha:abc1234 or a tag such as 1.4.0")
)

type Reference struct {
	Kind   ReferenceKind
	Raw    string
	Number int
	Prefix string
}

func ParseReference(raw string) (Reference, error) {
	switch {
	case idPattern.MatchString(raw):
		return Reference{Kind: ByID, Raw: raw}, nil
	case raw == string(ByLatest):
		return Reference{Kind: ByLatest, Raw: raw}, nil
	case numberPattern.MatchString(raw):
		number, err := strconv.Atoi(raw[1:])
		return Reference{Kind: ByNumber, Raw: raw, Number: number}, err
	case strings.HasPrefix(raw, "sha:"):
		return commitReference(raw)
	case tagPattern.MatchString(raw):
		return Reference{Kind: ByTag, Raw: raw}, nil
	}
	return Reference{}, errReference
}

func commitReference(raw string) (Reference, error) {
	prefix := strings.ToLower(strings.TrimPrefix(raw, "sha:"))
	if !prefixPattern.MatchString(prefix) {
		return Reference{}, errReference
	}
	return Reference{Kind: ByCommit, Raw: raw, Prefix: prefix}, nil
}
```

```go
const commitCandidates = 100

var errAmbiguousCommit = apperror.Invalid("that commit prefix matches more than one commit").
	WithHint("send more characters of the commit, up to the full 40")

func (u ReleasesUsecase) Resolve(ctx context.Context, serviceSlug, ref string) (entities.Release, error) {
	service, err := u.services.FindService(ctx, serviceSlug)
	if err != nil {
		return entities.Release{}, err
	}
	return u.resolveIn(ctx, service, ref)
}

func (u ReleasesUsecase) ResolveFor(ctx context.Context, a actor.Actor, serviceSlug, ref string) (entities.Release, error) {
	service, err := u.visibleService(ctx, a, serviceSlug)
	if err != nil {
		return entities.Release{}, err
	}
	return u.resolveIn(ctx, service, ref)
}

func (u ReleasesUsecase) resolveIn(ctx context.Context, service entities.ServiceRef, raw string) (entities.Release, error) {
	ref, err := entities.ParseReference(raw)
	if err != nil {
		return entities.Release{}, err
	}
	rel, found, err := u.lookup(ctx, service.ID, ref)
	if err == nil && !found {
		return entities.Release{}, notFoundIn(service, raw)
	}
	return rel, err
}

func (u ReleasesUsecase) lookup(ctx context.Context, serviceID string, ref entities.Reference) (entities.Release, bool, error) {
	switch ref.Kind {
	case entities.ByID:
		return u.byID(ctx, serviceID, ref.Raw)
	case entities.ByLatest:
		return u.store.LatestBuilt(ctx, serviceID)
	case entities.ByNumber:
		return u.store.ByNumber(ctx, serviceID, ref.Number)
	case entities.ByCommit:
		return u.byCommit(ctx, serviceID, ref.Prefix)
	}
	return u.store.BuiltByTag(ctx, serviceID, ref.Raw)
}

func (u ReleasesUsecase) byID(ctx context.Context, serviceID, id string) (entities.Release, bool, error) {
	rel, err := u.store.FindByID(ctx, id)
	if apperror.CodeOf(err) == apperror.CodeNotFound {
		return entities.Release{}, false, nil
	}
	return rel, err == nil && rel.ServiceID == serviceID, err
}

func (u ReleasesUsecase) byCommit(ctx context.Context, serviceID, prefix string) (entities.Release, bool, error) {
	matches, err := u.store.BuiltByCommitPrefix(ctx, serviceID, prefix, commitCandidates)
	if err != nil || len(matches) == 0 {
		return entities.Release{}, false, err
	}
	for _, rel := range matches[1:] {
		if rel.CommitSHA != matches[0].CommitSHA {
			return entities.Release{}, false, errAmbiguousCommit
		}
	}
	return matches[0], true, nil
}
```

```go
	if err := checkTargets(targets); err != nil {
		return nil, err
	}
	plans, failures := []plan{}, []targetFailure{}
	for i, t := range targets {
		p, err := u.batchable(ctx, planOne, t)
		if err != nil {
			failures = append(failures, failureOf(i, err))
			continue
		}
		plans = append(plans, p)
	}
	return plans, refusal(failures)
}

func (u DeploymentsUsecase) batchable(ctx context.Context, planOne planner, t Target) (plan, error) {
	p, err := planOne(t)
	if err != nil {
		return plan{}, err
	}
	if p.gate == authz.NeedsApproval {
		return plan{}, errBatchNeedsApproval
	}
	_, err = u.idle(ctx, p.service.ID, p.env)
	return p, err
}

func (u DeploymentsUsecase) scheduleAll(ctx context.Context, plans []plan) ([]entities.Deployment, error) {
	pending := make([]entities.Deployment, 0, len(plans))
	for _, p := range plans {
		pending = append(pending, newDeployment(p))
	}
	created, err := u.store.ScheduleAll(ctx, pending)
	if err != nil {
		return nil, err
	}

	}
	return created, nil
}

func checkTargets(targets []Target) error {
	if len(targets) == 0 || len(targets) > MaxTargets {
		return errTargetCount
	}
	seen := map[Target]bool{}
	for i, t := range targets {
		if t.Service == "" || t.Environment == "" {
			return errIncompleteTarget.WithField(targetField(i))
		}
		if seen[t] {
			return errRepeatedTarget.WithField(targetField(i))
		}
		seen[t] = true
	}
	return nil
}

func failureOf(index int, err error) targetFailure {
	failure := targetFailure{Index: index, Code: apperror.CodeOf(err), Message: "internal error", err: err}
	if failure.Code != apperror.CodeInternal {
		failure.Message = err.Error()
	}
	return failure
}

	if len(failures) == 0 {
		return nil

	lead := leading(failures)
	var appErr *apperror.AppError
	if !errors.As(lead.err, &appErr) {
		return lead.err
	}
	return appErr.WithField(targetField(lead.Index)).WithDetails(map[string]any{"targets": failures})
}

func leading(failures []targetFailure) targetFailure {
	for _, f := range failures {
		if f.Code == apperror.CodeApprovalRequired {
			return f
		}
	}
	return failures[0]
}
```

```go
import (
	"bytes"

	"errors"

	"reflect"

	"github.com/adrianozp/platform/pkg/apperror"

const patchShape = `send {"spec": {...}, "env": {"NAME": "value" or null}, "message": "..."}`

var (
	errPatchNotObject = apperror.Invalid("a merge patch must be a JSON object").WithHint(patchShape)
	errSpecRemoved    = apperror.Invalid("spec cannot be removed").WithField("spec").
				WithHint("send only the spec fields to change; null removes one field, not the whole spec")
	errEnvRemoved = apperror.Invalid("env cannot be removed as a whole").WithField("env").
			WithHint("set each variable to remove to null")
	errMessageNotText = apperror.Invalid("message must be a string").WithField("message")
	errEnvValue       = apperror.Invalid("env values must be strings, or null to remove one").WithField("env")
)

type patched struct {
	Spec Spec              `json:"spec"`
	Env  map[string]string `json:"env"`
}

func MergePatch(target, patch any) any {
	fields, isObject := patch.(map[string]any)
	if !isObject {
		return patch
	}
	merged, isObject := target.(map[string]any)
	if !isObject {
		merged = map[string]any{}
	}
	for key, value := range fields {
		if value == nil {
			delete(merged, key)
			continue
		}
		merged[key] = MergePatch(merged[key], value)
	}
	return merged
}

func PatchChangeSet(current Revision, raw []byte) (ChangeSet, error) {
	patch, err := patchObject(raw)
	if err != nil {
		return ChangeSet{}, err
	}
	message, err := takeMessage(patch)
	if err != nil {
		return ChangeSet{}, err
	}
	result, err := applyPatch(current, patch)
	if err != nil {
		return ChangeSet{}, err
	}
	cs := ChangeSet{Message: message}
	if _, sent := patch["spec"]; sent {
		cs.Spec = &result.Spec
	}
	cs.SetEnv, cs.UnsetEnv = envChanges(current.Env, result.Env)
	return cs, nil
}

func patchObject(raw []byte) (map[string]any, error) {
	var patch map[string]any
	if err := json.Unmarshal(raw, &patch); err != nil || patch == nil {
		return nil, errPatchNotObject
	}
	if value, sent := patch["spec"]; sent && value == nil {
		return nil, errSpecRemoved
	}
	if value, sent := patch["env"]; sent && value == nil {
		return nil, errEnvRemoved
	}
	return patch, nil
}

func takeMessage(patch map[string]any) (string, error) {
	value, sent := patch["message"]
	delete(patch, "message")
	if !sent {
		return "", nil
	}
	message, isText := value.(string)
	if !isText {
		return "", errMessageNotText
	}
	return message, nil
}

func applyPatch(current Revision, patch map[string]any) (patched, error) {
	var base any
	raw, err := json.Marshal(patched{Spec: current.Spec, Env: current.Env})
	if err == nil {
		err = json.Unmarshal(raw, &base)
	}
	if err == nil {
		raw, err = json.Marshal(MergePatch(base, patch))
	}
	if err != nil {
		return patched{}, err
	}
	decoder := json.NewDecoder(bytes.NewReader(raw))
	decoder.DisallowUnknownFields()
	var result patched
	return result, patchError(decoder.Decode(&result))
}

func patchError(err error) error {
	var typed *json.UnmarshalTypeError
	switch {
	case err == nil:
		return nil
	case errors.As(err, &typed) && typed.Field == "env":
		return errEnvValue
	case errors.As(err, &typed):
		return apperror.Invalid(typed.Field + " must be " + kindOf(typed.Type)).WithField(typed.Field)
	}
	quoted, unknown := strings.CutPrefix(err.Error(), "json: unknown field ")
	if !unknown {
		return apperror.Invalid("the patched config is not valid: " + err.Error()).WithHint(patchShape)
	}
	field, _ := strconv.Unquote(quoted)
	return apperror.Invalid(fmt.Sprintf("unknown field %q", field)).WithField(field).
		WithHint("a merge patch changes spec and env only; spec accepts: " + strings.Join(specFields(), ", "))
}

func kindOf(t reflect.Type) string {
	switch t.Kind() {
	case reflect.String:
		return "a string"
	case reflect.Bool:
		return "true or false"
	case reflect.Slice:
		return "an array"
	case reflect.Struct, reflect.Map:
		return "an object"
	}
	return "a whole number"
}

func specFields() []string {
	t := reflect.TypeFor[Spec]()
	names := make([]string, 0, t.NumField())
	for i := range t.NumField() {
		name, _, _ := strings.Cut(t.Field(i).Tag.Get("json"), ",")
		names = append(names, name)
	}
	return names
}

func envChanges(before, after map[string]string) (map[string]string, []string) {
	set, unset := map[string]string{}, []string{}
	for name, value := range after {
		if old, had := before[name]; !had || old != value {
			set[name] = value
		}
	}
	for name := range before {
		if _, kept := after[name]; !kept {
			unset = append(unset, name)
		}
	}
	slices.Sort(unset)
	return set, unset
}
```

```go
		return nil
	}

func (u SearchUsecase) visibleServices(ctx context.Context, a actor.Actor, teamSlug string) (map[string]entities.ServiceRef, error) {
	teamID, err := u.grantedTeam(ctx, a, teamSlug)
	if err != nil {
		return nil, err
	}
	services, err := u.directory.Services(ctx)
	if err != nil {
		return nil, err
	}
	visible := map[string]entities.ServiceRef{}
	for _, s := range services {
		if a.Sees(s.OwnerTeamID) && (teamID == "" || s.OwnerTeamID == teamID) {
			visible[s.ID] = s
		}
	}
	return visible, nil
}

func (u SearchUsecase) grantedTeam(ctx context.Context, a actor.Actor, teamSlug string) (string, error) {
	if teamSlug == "" {
		return "", nil
	}
	teamID, err := u.directory.TeamID(ctx, teamSlug)
	if err != nil {
		return "", err
	}
	if !a.Sees(teamID) {
		return "", apperror.TeamNotGranted(teamSlug)
	}
	return teamID, nil
}

func within(matches []entities.Match, visible map[string]entities.ServiceRef) []entities.Match {
	result := []entities.Match{}
	for _, m := range matches {
		if service, seen := visible[m.ServiceID]; seen {
			m.ServiceSlug = service.Slug
			result = append(result, m)
		}
	}
	slices.SortFunc(result, func(a, b entities.Match) int {
		return cmp.Or(cmp.Compare(a.ServiceSlug, b.ServiceSlug), cmp.Compare(a.Environment, b.Environment))
	})
	return result
}
```

```go
type Requests interface {

type Drain struct {
	once *sync.Once
	done chan struct{}
}

func NewDrain() *Drain {
	return &Drain{once: &sync.Once{}, done: make(chan struct{})}
}

func (d *Drain) Close() {
	d.once.Do(func() { close(d.done) })
}

type Waiter struct {
	drain    *Drain
	requests Requests
	every    time.Duration
}

func NewWaiter(drain *Drain, requests Requests) Waiter {
	return Waiter{drain: drain, requests: requests, every: time.Second}
}

func Duration(c *gin.Context) (time.Duration, bool) {
	raw := c.Query("wait")
	if raw == "" {
		return 0, true
	}
	d, err := time.ParseDuration(raw)
	if err != nil || d <= 0 || d > Max {
		httperror.Abort(c, errDuration)
		return 0, false
	}
	return d, true
}

func Read[T any](c *gin.Context, w Waiter, d time.Duration, load Load[T], final func(T) bool) {
	value, err := load(c.Request.Context())
	if err != nil {
		httperror.Abort(c, err)
		return
	}
	if d == 0 {
		c.JSON(http.StatusOK, value)
		return
	}
	settle(c, w, d, value, load, final)
}

func Started[T any](c *gin.Context, w Waiter, d time.Duration, value T, err error, load Load[T], final func(T) bool) {
	var pending *approval.Pending

	case errors.As(err, &pending) && d > 0:
		settle(c, w, d, requestState{Pending: *pending}, w.request(c, *pending), requestState.settled)
	case err != nil:
		httperror.Abort(c, err)
	case d == 0:
		c.JSON(http.StatusAccepted, value)
	default:
		settle(c, w, d, value, load, final)

func settle[T any](c *gin.Context, w Waiter, d time.Duration, value T, load Load[T], final func(T) bool) {
	value, err := Until(c.Request.Context(), w, d, value, load, final)
	if err != nil {
		httperror.Abort(c, err)
		return
	}
	if final(value) {
		c.JSON(http.StatusOK, value)
		return
	}
	c.Header("Retry-After", RetryAfter)
	c.JSON(http.StatusAccepted, value)
}

func Until[T any](ctx context.Context, w Waiter, d time.Duration, value T, load Load[T], final func(T) bool) (T, error) {
	if final(value) {
		return value, nil
	}
	f := &follow[T]{value: value, load: load, final: final}
	err := w.poll(ctx, time.Now().Add(d), f.settled)
	return f.value, err
}

type follow[T any] struct {
	value T
	load  Load[T]
	final func(T) bool
}

func (f *follow[T]) settled(ctx context.Context) (bool, error) {
	next, err := f.load(ctx)
	if err != nil {
		return false, err
	}
	f.value = next
	return f.final(next), nil
}

func (w Waiter) poll(ctx context.Context, deadline time.Time, settled func(context.Context) (bool, error)) error {
	for w.pause(ctx, deadline) {
		if done, err := settled(ctx); done || err != nil {
			return err
		}
	}
	return nil
}

func (w Waiter) pause(ctx context.Context, deadline time.Time) bool {
	remaining := time.Until(deadline)
	if remaining <= 0 {
		return false
	}
	timer := time.NewTimer(min(w.every, remaining))
	defer timer.Stop()
	select {
	case <-ctx.Done():
		return false
	case <-w.drain.done:
		return false
	case <-timer.C:
		return true
	}
}

type requestState struct {
	approval.Pending
	final bool
}

func (s requestState) settled() bool {
	return s.final
}

		status, final, err := w.requests.RequestState(ctx, a, pending.ID)
		pending.Status = status
		return requestState{Pending: pending, final: final}, err
	}
}
```
