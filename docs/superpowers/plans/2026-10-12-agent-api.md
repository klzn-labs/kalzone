# Agent-grade API (3a: one contract) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every `/api/v1` route declares itself as an operation with metadata; the control plane serves a generated OpenAPI 3.1 document at `/api/v1/openapi.json`; every list answers `{"items", "next_cursor"}` with `?limit`/`?cursor`; errors carry `hint`, `field` and `details`; bodies are strict; `GET /deployments/:id` carries an `events_summary` and the full log is paged at `/deployments/:id/events`; tokens show team slugs; a bogus request status is a `400`; and the integration suite validates every API response against the document.

**Architecture:** A new `internal/apispec` package holds `Operation`, a `Catalog`, the list envelope and the document builder (swaggest/openapi-go with schema interceptors). `httpserver.API` stops embedding the gin group: its only method, `Handle(ops...)`, registers the route and records the operation, so an undeclared `/api/v1` route cannot compile, and a parity test catches routes registered elsewhere. `pkg/page` parses limits and opaque cursors; keyset lists paginate in the usecases over new `before`/`after` repository parameters, small lists in memory in the handlers. `httperror.BindStrict` replaces the lenient binder on `/api/v1` only.

**Tech Stack:** Go 1.26, Gin, Uber fx, GORM on MySQL 8, testify; new: `github.com/swaggest/openapi-go` v0.2.61 and `github.com/swaggest/jsonschema-go` v0.3.78 (document), `github.com/getkin/kin-openapi` v0.149.0 (response validation in the integration suite).

**Spec:** `docs/superpowers/specs/2026-10-12-agent-api-design.md`, sections 1–11 and 17–18 (3a). Sections 12–16 (waiting, release references, config patch, batch, config search) are sub-project 3b and out of scope here.

**How the code was checked:** every code block below was applied to a scratch worktree of `e080b07` (the spec commit; its code equals `0a06f0e`) task by task in this order: `go build ./... && go vet ./... && gofmt -l .` clean after every task, `go test -p 1 -count=1 ./...` green after Tasks 1–8, and the clean-code hook (size, nesting, comments) clean on every changed Go file, tests included, except the pre-existing 23-line `Test_ADeployIsClaimedRunAndBecomesLive` in `deploys_test.go`, where this plan only renames one JSON key. Diffs are against `0a06f0e`; apply them with the shown context, or by hand.

## Global Constraints

- Function bodies ≤ 20 lines, at most 2 levels of nesting, **no comments** in any file: Go, SQL, HTML, Markdown code samples, tests (user rule; a hook enforces it). `ALLOW_COMMENTS` is never used.
- One commit per layer, bottom-up: storage (Task 1), rules (Tasks 2–3), handlers + wiring + integration tests (Tasks 4–7), docs (Task 8). No fix/wip commits, no `Co-Authored-By`, do not push. Commit messages follow the repo style (imperative sentence, no prefix).
- Tests run with `-p 1`: the MySQL-backed packages share one test database (`make test`).
- Change `/api/v1` in place; no `v2`. Untouched: the build callbacks `POST /api/v1/releases/:id/{started,built,failed}`, `/agent/v1`, `/queued/v1`, `/webhooks/github` and the web UI; they keep `httperror.BindJSON`.
- Lists: `{"items": [...], "next_cursor": "…"}`, `next_cursor` only when there is more; `?limit` 1–100, default 20, otherwise `400` with `field: limit`; `?cursor` opaque (base64url of a key), garbage is `400` with `field: cursor`.
- Errors: `{"error": {"code", "message", "hint", "field", "details", "required_scope", "team"}}`, the last five only when set.
- A property in the document is required unless its json tag has `omitempty`; struct objects have `additionalProperties: false`; arrays and maps are never null; schema names are `<Package><Type>` without `DTO`, `entities` packages take the domain name, list envelopes `<Item>Page`, gated 202 answers `<Item>OrChangeRequest`.
- Security in the document: `[{token: [scope]}, {session: []}]`, or only `session` for `setAdmin`. `getOpenAPI`, `getMe`, `getWhoami` declare no scope; `/api/v1/openapi.json` joins the bearer guard's read-free list.
- `POST /deployments` takes `release` (a release id) instead of `release_id`.
- `GET /deployments/:id` adds `events_summary {total, progress_lines, phases [{name: waiting|running, seconds}], tail (last 20 non-progress lines of the newest 500), log}`; a progress line matches `^\W*[0-9a-f]{12}\b`.
- `GET /deployments/:id/events`: oldest first; `?tail=N` (1–100) not with `?cursor`; `next_cursor` when the page is full or the deployment is pending or in progress.

## Review Focus

1. A client follows `next_cursor` while new rows arrive (a release is built, an audit event is written): pages must neither repeat nor skip existing rows. Keyset queries use `number <` or `(at, id) <` instead of offsets — pinned by `Test_ListByService_ContinuesBelowANumber`, `Test_List_ContinuesAfterEventsOfTheSameInstant` (three events in the same millisecond) and `Test_Requests_ListContinuesAfterACreationTimeAndID` in Task 1.
2. An agent follows a running deployment's log with an empty page in between: the cursor must survive the empty page, and stop only after the deployment finishes. Task 3 `Test_EventsFor_KeepsACursorWhileTheDeploymentRuns`; Task 7 `Test_ARunningDeploymentsLogCanBeFollowed`.
3. A hidden service must not leak through the new list and log endpoints to a token of another team: `PageFor`, `RevisionsFor`, `SummaryFor` and `EventsFor` check `actor.Sees` before reading. Task 3 `Test_PageFor_NeedsAServiceTheCallerSees`, `Test_PageFor_NamesTheMissingQueryParameter`, `Test_SummaryFor_CountsEveryLineAndKeepsTheTail` (hidden branch), `Test_RevisionsFor_PagesNewestFirst` (hidden branch).
4. A secret value must stay out of everything new: the summary, the events endpoint and the document never carry config values, and `listSecrets` answers names only. The existing `Test_ASecretValueNeverComesBack` and `Test_ASecretRequestNeverShowsItsValue` now also run with response validation (Task 7); read the generated `ConfigsSecretInfo` schema once by hand: `name`, `set_by`, `set_at` only.
5. A handler that returns a field the document does not describe, or `null` for a list, breaks agents silently. Every integration response is validated against the document from Task 7 on (`contract.check`), and a negative check was run by hand during verification: an extra property, `"items": null` and a missing required field are each rejected.

package page

import (
	"encoding/base64"
	"slices"
	"strconv"
	"strings"
	"time"

	"github.com/klzn-labs/kalzone/pkg/apperror"
)

const (
	DefaultLimit = 20
	MaxLimit     = 100
)

var (
	errLimit = apperror.Invalid("limit must be a whole number from 1 to 100").WithField("limit").
			WithHint("leave limit out for 20 items, or send 1 to 100")
	errCursor = apperror.Invalid("cursor is not valid").WithField("cursor").
			WithHint("send next_cursor from the previous page unchanged, or start again without cursor")
)

type Request struct {
	Limit int
	After string
}

type Page[T any] struct {
	Items []T
	Next  string
}

func Parse(limit, cursor string) (Request, error) {
	n, err := parseLimit(limit)
	if err != nil {
		return Request{}, err
	}
	after, err := decode(cursor)
	return Request{Limit: n, After: after}, err
}

func First(limit int) Request {
	return Request{Limit: limit}
}

func parseLimit(raw string) (int, error) {
	if raw == "" {
		return DefaultLimit, nil
	}
	n, err := strconv.Atoi(raw)
	if err != nil || n < 1 || n > MaxLimit {
		return 0, errLimit
	}
	return n, nil
}

func decode(cursor string) (string, error) {
	if cursor == "" {
		return "", nil
	}
	raw, err := base64.RawURLEncoding.DecodeString(cursor)
	if err != nil || len(raw) == 0 {
		return "", errCursor
	}
	return string(raw), nil
}

func Encode(key string) string {
	return base64.RawURLEncoding.EncodeToString([]byte(key))
}

func (r Request) Fetch() int {
	return r.Limit + 1
}

func (r Request) Number() (int, error) {
	if r.After == "" {
		return 0, nil
	}
	n, err := strconv.Atoi(r.After)
	if err != nil || n < 0 {
		return 0, errCursor
	}
	return n, nil
}

func TimeKey(at time.Time, id string) string {
	return at.UTC().Format(time.RFC3339Nano) + "|" + id
}

func (r Request) Time() (*time.Time, string, error) {
	if r.After == "" {
		return nil, "", nil
	}
	raw, id, found := strings.Cut(r.After, "|")
	at, err := time.Parse(time.RFC3339Nano, raw)
	if !found || err != nil {
		return nil, "", errCursor
	}
	return &at, id, nil
}

func Cut[T any](items []T, r Request, key func(T) string) Page[T] {
	if len(items) <= r.Limit {
		return Page[T]{Items: items}
	}
	kept := items[:r.Limit]
	return Page[T]{Items: kept, Next: Encode(key(kept[len(kept)-1]))}
}

func Window[T any](all []T, r Request, key func(T) string) (Page[T], error) {
	start, err := startOf(all, r.After, key)
	if err != nil {
		return Page[T]{}, err
	}
	end := min(start+r.Fetch(), len(all))
	return Cut(all[start:end], r, key), nil
}

func startOf[T any](all []T, after string, key func(T) string) (int, error) {
	if after == "" {
		return 0, nil
	}
	i := slices.IndexFunc(all, func(item T) bool { return key(item) == after })
	if i < 0 {
		return 0, errCursor
	}
	return i + 1, nil
}

package entities

import (
	"regexp"
	"time"

const (
	SummaryTail   = 20
	SummaryWindow = 500
)

var progressLine = regexp.MustCompile(`^\W*[0-9a-f]{12}\b`)

type Phase struct {
	Name    string
	Seconds int
}

type Summary struct {
	Total         int
	ProgressLines int
	Phases        []Phase
	Tail          []Event
}

func Summarize(d Deployment, recent []Event, total int, now time.Time) Summary {
	s := Summary{Total: total, Phases: d.Phases(now), Tail: []Event{}}
	for _, e := range recent {
		if progressLine.MatchString(e.Message) {
			s.ProgressLines++
			continue
		}
		s.Tail = append(s.Tail, e)
	}
	s.Tail = s.Tail[max(0, len(s.Tail)-SummaryTail):]
	return s
}

func (d Deployment) Phases(now time.Time) []Phase {
	waiting := Phase{Name: "waiting", Seconds: seconds(d.CreatedAt, firstOf(now, d.StartedAt, d.FinishedAt))}
	if d.StartedAt == nil {
		return []Phase{waiting}
	}
	running := Phase{Name: "running", Seconds: seconds(*d.StartedAt, firstOf(now, d.FinishedAt))}
	return []Phase{waiting, running}
}

func firstOf(fallback time.Time, times ...*time.Time) time.Time {
	for _, t := range times {
		if t != nil {
			return *t
		}
	}
	return fallback
}

func seconds(from, to time.Time) int {
	return int(to.Sub(from).Round(time.Second) / time.Second)
}

func Build(c *Catalog, baseURL string) ([]byte, error) {
	r := openapi31.NewReflector()
	r.DefaultOptions = append(r.DefaultOptions, schemaRules()...)
	r.Spec.Info.WithTitle("Platform API").WithVersion("1").WithDescription("The internal developer platform's API for people and agents.")

	r.Spec.SetHTTPBearerTokenSecurity("token", "plat_…", "an access token from the Tokens page or POST /api/v1/tokens")

		if err := add(r, op); err != nil {

func DocPath(ginPath string) string {
	return BasePath + ginParam.ReplaceAllString(ginPath, "{$1}")
}

var (
	errIncomplete  = errors.New("an operation needs an ID, a summary and a status")
	errGatedAnswer = errors.New("a gated operation that answers 202 must answer apispec.OrChangeRequest")
)

func check(op Operation) error {
	if op.ID == "" || op.Summary == "" || op.Status == 0 {
		return errIncomplete
	}
	if _, either := op.Response.(jsonschema.OneOfExposer); op.Gated && op.Status == http.StatusAccepted && !either {
		return errGatedAnswer
	}
	return nil
}

func add(r *openapi31.Reflector, op Operation) error {
	if err := check(op); err != nil {
		return err
	}
	oc, err := r.NewOperationContext(op.Method, DocPath(op.Path))
	if err != nil {
		return err
	}
	describe(oc, op)
	request(oc, op)
	respond(oc, op)
	return r.AddOperation(oc)
}

func describe(oc openapi.OperationContext, op Operation) {
	oc.SetID(op.ID)
	oc.SetSummary(op.Summary)
	oc.SetTags(strings.Split(strings.TrimPrefix(op.Path, "/"), "/")[0])
	if op.Gated {
		oc.SetDescription(gatedNote)
	}
	if !op.Session {
		oc.AddSecurity("token", scopesOf(op)...)
	}
	oc.AddSecurity("session")
}

	if op.Scope == "" {
		return nil
	}
	return []string{string(op.Scope)}
}

	if op.Params != nil {
		oc.AddReqStructure(op.Params)
	}
	if op.Body != nil {
		oc.AddReqStructure(op.Body)
	}
}

	oc.AddRespStructure(op.Response, openapi.WithHTTPStatus(op.Status))
	if op.Gated && op.Status != http.StatusAccepted {
		oc.AddRespStructure(new(approval.Pending), openapi.WithHTTPStatus(http.StatusAccepted))

func closeObjects(params jsonschema.InterceptSchemaParams) (bool, error) {
	if params.Processed && params.Value.Kind() == reflect.Struct && len(params.Schema.Properties) > 0 {
		params.Schema.AdditionalProperties = (&jsonschema.SchemaOrBool{}).WithTypeBoolean(false)
	}
	return false, nil
}

func requireUnlessOmitted(params jsonschema.InterceptPropParams) error {
	tag, tagged := params.Field.Tag.Lookup("json")
	if !params.Processed || !tagged || tag == "-" || strings.Contains(tag, ",omitempty") {
		return nil

	}
	return nil
}

	}
}

func BindStrict(c *gin.Context, out any) bool {
	if err := DecodeStrict(c.Request.Body, out); err != nil {
		Abort(c, err)
		return false
	}
	return true
}

func DecodeStrict(body io.Reader, out any) error {
	decoder := json.NewDecoder(body)
	decoder.DisallowUnknownFields()
	if err := decoder.Decode(out); err != nil {
		return decodeError(err, acceptedFields(out))
	}
	return validationError(binding.Validator.ValidateStruct(out), out)
}

func decodeError(err error, accepted []string) error {
	var syntax *json.SyntaxError
	var typed *json.UnmarshalTypeError
	switch {
	case errors.Is(err, io.EOF):
		return withAccepted(apperror.Invalid("the request body is empty"), "send a JSON object", accepted)
	case errors.As(err, &syntax):
		return apperror.Invalid("the request body is not valid JSON").WithHint(fmt.Sprintf("check the JSON near byte %d", syntax.Offset))
	case errors.As(err, &typed):
		return apperror.Invalid(typed.Field + " must be " + jsonKind(typed.Type)).WithField(typed.Field)
	}
	if field, unknown := unknownField(err); unknown {
		return withAccepted(apperror.Invalid(fmt.Sprintf("unknown field %q", field)).WithField(field), "remove "+field, accepted)
	}
	return apperror.Invalid("the request body is not valid JSON: " + err.Error())
}

func withAccepted(e *apperror.AppError, hint string, accepted []string) *apperror.AppError {
	return e.WithHint(hint + "; this body accepts: " + strings.Join(accepted, ", ")).
		WithDetails(map[string]any{"accepted": accepted})
}

func unknownField(err error) (string, bool) {
	quoted, found := strings.CutPrefix(err.Error(), "json: unknown field ")
	if !found {
		return "", false
	}
	field, unquoteErr := strconv.Unquote(quoted)
	return field, unquoteErr == nil
}

func validationError(err error, out any) error {
	var failures validator.ValidationErrors
	if !errors.As(err, &failures) || len(failures) == 0 {
		return err
	}
	field := jsonName(out, failures[0].StructField())
	if failures[0].Tag() == "required" {
		return apperror.Invalid(field + " is required").WithField(field).WithHint("send " + field)
	}
	return apperror.Invalid(field + " is not valid: " + failures[0].Tag()).WithField(field)
}

func jsonKind(t reflect.Type) string {
	switch t.Kind() {
	case reflect.String:
		return "a string"
	case reflect.Bool:
		return "true or false"
	case reflect.Slice, reflect.Array:
		return "an array"
	case reflect.Map, reflect.Struct:
		return "an object"
	}
	return "a number"
}

func acceptedFields(out any) []string {
	t := structType(out)
	names := []string{}
	for i := 0; t != nil && i < t.NumField(); i++ {
		if name := tagName(t.Field(i)); name != "-" {
			names = append(names, name)
		}
	}
	return names
}

func jsonName(out any, goName string) string {
	t := structType(out)
	if t == nil {
		return goName
	}
	if field, found := t.FieldByName(goName); found {
		return tagName(field)
	}
	return goName
}

func structType(out any) reflect.Type {
	t := reflect.TypeOf(out)
	for t != nil && t.Kind() == reflect.Pointer {
		t = t.Elem()
	}
	if t == nil || t.Kind() != reflect.Struct {
		return nil
	}
	return t
}

func tagName(field reflect.StructField) string {
	name, _, _ := strings.Cut(field.Tag.Get("json"), ",")
	if name == "" {
		return field.Name
	}
	return name
}

import (

	"github.com/getkin/kin-openapi/routers/legacy"
	"github.com/stretchr/testify/require"
)

type contract struct {
	router routers.Router
}

func loadContract(t *testing.T, catalog *apispec.Catalog) *contract {
	t.Helper()
	raw, err := apispec.Build(catalog, "http://platform.test")
	require.NoError(t, err)
	doc, err := openapi3.NewLoader().LoadFromData(raw)
	require.NoError(t, err)
	require.NoError(t, doc.Validate(context.Background()))
	doc.Servers = nil
	router, err := legacy.NewRouter(doc)
	require.NoError(t, err)
	return &contract{router: router}
}

func (c *contract) check(t *testing.T, req *http.Request, resp Response) {
	t.Helper()
	route, params, err := c.router.FindRoute(req)
	if err != nil {
		return
	}
	input := &openapi3filter.ResponseValidationInput{
		RequestValidationInput: &openapi3filter.RequestValidationInput{Request: req, PathParams: params, Route: route},
		Status:                 resp.Status, Header: resp.Header,
		Options: &openapi3filter.Options{IncludeResponseStatus: true},
	}
	input.SetBodyBytes([]byte(resp.Body))
	err = openapi3filter.ValidateResponse(context.Background(), input)
	require.NoError(t, err, "%s %s answered %d %s", req.Method, req.URL.Path, resp.Status, resp.Body)
}

## Working with the API

Every call, field, scope and status value is described in
`GET https://platform.kalz.one/api/v1/openapi.json`. Read it before calling
anything; do not guess routes from the source. Send
`Authorization: Bearer <token>`; `GET /api/v1/whoami` shows what the token may do.
Lists come in pages of `{"items", "next_cursor"}`, and a refused call says in
`error.hint` how to fix it.

## Shipping a change

1. Build `api` or `web`: `POST /api/v1/releases` with `{"service", "ref"}`, or the
   Releases tab, or auto-build on push. A build of `api` is shared with `worker` and
   `importer`, which get a release with the same digest and their own number.
2. Wait until `GET /api/v1/releases/<id>` says `built`.
3. Deploy each service to dev: `POST /api/v1/deployments` with
   `{"service", "environment": "dev", "release"}`; follow
   `GET /api/v1/deployments/<id>` until `succeeded`, and read its `events_summary`
   when it fails.
4. Promote to prod: `POST /api/v1/deployments/promotions` with
   `{"service", "from": "dev", "to": "prod"}`. A token without bypass gets `202`
   with a change request; a maintainer approves it in the browser, and
   `GET /api/v1/requests/<id>` says `executed` with the deployment.

## How the cutover went

For each service: copy the variables from `infra-plateful/config/<svc>.env` and the
secrets from the host into the platform, register the live image tag and deploy it,
move the old Traefik route file out of `/opt/plateful/dynamic`, check from the
container logs that real traffic reaches the new colour and only health checks reach
the old one, then stop and remove the old containers. The old route files and
deployctl state are in `~deploy/retired-state/` on the host.

## Gaps found while mapping

1. **Internal routes.** Closed: a spec can be `internal`, routed on the environment's

2. **One image, several services.** Closed: a finished build is shared with every

3. **More than one host.** Closed: a spec takes `aliases`.
4. **Replicas and CPU** are still ignored by the compose runtime (see the deploys

5. **Workers in dev.** Closed: the NATS stream is gone; worker and importer talk
