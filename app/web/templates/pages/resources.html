Queues

One service hands work to another. The consumer receives each message once, at a rate it can take.

  • Dead letters you can replay or purge
  • An adaptive rate that slows down when the database is busy

Crons

{{template "offering-usage" index $d.Usage "cron"}}

Kalzone calls a path on one of your services on a schedule, so nothing in your code has to keep time.

  • A cron schedule with an optional JSON payload
  • A timeout per run and the last 50 runs kept
  • Pause, resume or run it now
